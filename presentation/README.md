# Capstone Presentation

This folder contains the presentation deliverables for the semantic retrieval
circuit submission.

- `retrieval_head_atlas_capstone_presentation.pptx` is the final slide deck.
- `retrieval_head_atlas_capstone_speaker_notes.md` mirrors the embedded speaker
  notes for the recorded walkthrough.
- `assets/figures/` contains report-derived quantitative figures adapted for
  slides.
- `assets/generated/` contains narrative visuals generated specifically for the
  deck. These are explanatory visuals, not experimental evidence.

The PPTX has 15 slides and embedded speaker notes for each slide.
